# Скрябины — семейный архив

Сайт для семьи: история фамилий, дерево на 75 человек и 7 поколений (из
вашего файла `familytrace-backup__16_.json`), и админка для Марины
Алексеевны — добавлять родственников, фотографии, уточнять сведения.

## Вход в админку

Раздел «Админка» → пароль: **`Skryabin1990`**

Это простая защита паролем «для своих», а не банковский уровень
безопасности — пароль виден в исходном коде (`js/app.js`, константа
`ADMIN_PASSWORD`). Смените его на свой перед тем, как давать ссылку на
сайт кому-то за пределами семьи: откройте `js/app.js`, найдите строку

```js
const ADMIN_PASSWORD = "Skryabin1990";
```

и замените на что угодно.

## Что умеет сайт

- **Главная** — история семьи, карта мест (в том числе исчезнувших
  деревень), происхождение фамилий.
- **Дерево** — все люди, сгруппированные по поколениям (римские цифры,
  I — самые дальние известные предки).
- **Люди** — полный список с поиском и фильтром по линии (отец / мать /
  родня мужа).
- Открыв карточку человека, вы видите **как именно он приходится
  Марине** — это не вписано руками, а считается автоматически по связям
  в дереве (файл `js/relations.js`). Добавите нового человека и свяжете
  его с семьёй — подпись родства появится сама.
- **Фамилии** — происхождение фамилий рода (общие сведения об
  ономастике, не архивные факты о конкретно вашей семье — это указано
  на странице).
- **География** — деревни и город, где рождались члены семьи, с
  пометкой, какие из них официально упразднены.
- **Админка** (для Марины) — добавление людей, фотографий, связей;
  можно убрать отдельную ошибочную связь, не удаляя самого человека.

## Известная неточность в исходных данных

В вашем файле у Ларисы Ильиных указано **три родителя** одновременно:
Алексей и Татьяна Скрябины, и отдельно Виноградов Василий Александрович
(и её отчество «Васильевна» соответствует именно ему, а не Алексею). Я
это не стал молча чинить: сайт показывает всех троих, но в её карточке
через админку можно удалить лишнюю связь одной кнопкой «✕» рядом с
именем — как только вы решите, кто её настоящий отец.

## Как устроено хранение данных

- Исходное дерево (`js/seed-data.js`) — снимок вашего файла на момент
  сборки сайта, зашит в код и не меняется сам по себе.
- Всё, что Марина добавляет или редактирует через админку, копится
  **поверх** этого снимка — в localStorage браузера, на конкретном
  устройстве.
- Раздел «Админка → Резервная копия» — там можно скачать полный JSON
  (снимок + все правки) и загрузить его обратно. Это одновременно и
  бэкап, и способ перенести правки на другое устройство/браузер.
- Фотографии хранятся тем же способом (сжимаются до ~480px по ширине
  перед сохранением) — это удобно для пары десятков-сотни фото, но не
  предназначено для тысяч фотографий в высоком разрешении: у
  localStorage есть лимит около 5–10 МБ на сайт.

Если позже семья вырастет и захочется, чтобы Марина заходила с телефона
и с компьютера и видела одни и те же правки без ручного экспорта —
тогда есть смысл подключить настоящую базу данных (например Supabase).
Архитектура (`js/db.js`) сделана так, чтобы потом заменить только слой
хранения, не переписывая остальной сайт.

## Деплой

Обычный статический сайт + маленький Node-сервер `server.js` (без
зависимостей) — нужен только для платформ вроде Railway, которым
обязательно требуется процесс, слушающий `$PORT`.

**Railway** — просто загрузите проект (git или `railway up`), Railway
сам найдёт `package.json` и запустит `npm start`. Конфигурация уже в
`railway.json`.

**Netlify / Vercel** — деплой как обычный статический сайт (Framework
Preset: Other / без сборки), `server.js` в этом случае не нужен.

**Локально** — `node server.js`, затем открыть `http://localhost:3000`.

## Структура проекта

```
index.html          разметка, шрифты (PT Serif / PT Sans / IBM Plex Mono)
css/style.css        вся визуальная тема
js/seed-data.js       снимок вашего дерева на момент сборки
js/content.js         текст: происхождение фамилий, география
js/db.js              хранилище: снимок + правки поверх (localStorage)
js/relations.js        расчёт «кем приходится Марине» для любого человека
js/app.js              весь UI, маршрутизация, админка
server.js / package.json / railway.json   для деплоя
```
